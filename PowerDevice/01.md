# 1. 什么是功率器件？ (What is a Power Device? / パワーデバイスとは)

## 1-1 功率器件的作用 (Role of Power Devices / パワーデバイスの役割)

在我们的日常生活中，电能是不可或缺的。电能由发电厂产生，通过输配电网络输送到家庭、办公室、工厂等地，并被各种电器、照明设备、个人电脑和动力设备广泛使用。从发电到使用的整个过程中，电能会根据需要被转换成各种电压和电流。这项用于转换电能的控制、电路和器件技术统称为 **电力电子学 (Power Electronics / パワーエレクトロニクス)**。

用于这种电能转换的电力电子电路中的半导体器件，被称为 **功率器件 (Power Device / パワーデバイス)** 或 **功率半导体器件 (Power Semiconductor Device / パワー半導体デバイス)**。电力电子电路中的功率转换，是通过周期性的开关动作，将电能暂时储存在 **电感 (Coil / コイル)** 或 **电容 (Capacitor / コンデンサ)** 中，然后再根据需要取出电能来实现的。因此，功率器件的主要作用，就是作为开关来控制伴随这种转换产生的电流流动。

图1-1所示是一个被称为 **升压转换器 (Boost Converter / 昇圧コンバータ)** 的电路示例。通过交替地将功率器件A和B进行导通/关断（on/off）操作，可以将从输入端输入的能量传递到输出端。此时，如果让功率器件A以 **占空比 (Duty Cycle / デューティ比)** *D* 导通，输出电压 Vout 将被转换为输入电压 Vin 的 1/(1-D) 倍。

为了有效利用电能，需要有能够高效转换功率的电力电子电路。通常，通过减少部件数量和实现小型化，可以降低电路的成本。因此，电力电子电路在不断提高效率的同时，也在向小型化发展。而这种电力电子电路的进步，是由功率器件的性能提升所支撑的。

## 1-2 功率器件的基本工作原理 (Basic Operation of Power Devices / パワーデバイスの基本動作)

功率器件作为开关使用，其基本工作状态有三种：允许电流通过的 **“导通状态 (On-state / オン状態)”**、不允许电流通过的 **“关断状态 (Off-state / オフ状態)”**，以及从导通状态切换到关断状态或从关断状态切换到导通状态的 **“开关状态 (Switching state / スイッチング状態)”**。

首先，在处理电力时，即使在施加电压的情况下也能安全地保持关断状态是首要任务，因此，器件在不被破坏的情况下所能承受的电压，即 **耐压 (Withstand Voltage / 耐圧)**，是最重要的性能指标。

其次，为了实现高效的功率转换，必须减小功率器件产生的损耗。功率器件产生的损耗包括在导通状态下产生的 **导通损耗 (Conduction Loss / 導通損失)** 和在开关状态下产生的 **开关损耗 (Switching Loss / スイッチング損失)**。导通损耗是导通状态下的电流与器件内部电压降的乘积，因此，导通状态下的电阻（**导通电阻 (On-resistance / オン抵抗)**）或导通状态下的电压降（**导通电压 (On-voltage / オン電圧)**）被用作评估低损耗性能的指标。此外，开关损耗与导通/关断切换所需的时间成正比，因此 **开关时间 (Switching Time / スイッチング時間)** 和开关损耗被用作评估低损耗性能的指标。

综上所述，**耐压 (Withstand Voltage / 耐圧)**、**导通电阻 (On-resistance / オン抵抗)**（或 **导通电压 (On-voltage / オン電圧)**）以及 **开关时间 (Switching Time / スイッチング時間)**（或 **开关损耗 (Switching Loss / スイッチング損失)**）是功率器件的重要性能。

**电力电子电路 (Power Electronics Circuit / パワーエレクトロニクス回路)** 的性能，取决于其内部所使用的功率器件能承受的电压，因此，在确保必要耐压的同时，降低损耗，是改善功率器件性能的关键。

此外，功率器件的开关动作，通常伴随着大电流、高电压的变化。为了减少 **开关损耗 (Switching Loss / スイッチング損失)** 而进行高速开关操作时，会导致电流和电压的急剧变化。此时，电力电子电路中的 **寄生电感 (Parasitic Inductance / 寄生インダクタンス)** 和 **寄生电容 (Parasitic Capacitance / 寄生キャパシタンス)** 会产生 **浪涌电压 (Surge Voltage / サージ電圧)** 和 **浪涌电流 (Surge Current / サージ電流)**，这不仅是产生 **噪声 (Noise / ノイズ)** 的原因，也可能导致器件损坏。因此，开关损耗和噪声、损坏之间存在 **权衡关系 (Trade-off / トレードオフ)**。噪声不仅会影响电路中的其他元件，还会通过布线影响其他电路，因此电路产生的噪声强度受到法规的严格限制。为了满足这些规定而增加滤波器等电路，会导致成本上升、电路体积变大。因此，选择能够在满足噪声规范的同时，实现低损耗、高效率工作的功率器件至关重要。也就是说，改善开关损耗与噪声的权衡关系，也是对功率器件的一项要求。

![图1-2 电力电子电路对功率器件的性能要求](figure_1-2.png)

另外，对于功率器件的工作，不仅要求在正常的电路工作下，还要求在诸如瞬时停电或建筑物整体电源投入等非正常状态下也不能损坏。当功率器件损坏时，存储在电力电子电路内部的能量或从电源线供给的能量，会以大电流的形式流过，可能导致器件发热甚至起火。可以预见，高速开关时产生的浪涌电压和浪涌电流会使器件内部的电场强度变高，达到临界电场强度，从而引发 **雪崩击穿 (Avalanche Breakdown / アバランシェ降伏)**，导致器件损坏。因此，开关损耗和抵抗损坏的能力（**破坏耐量 (Destruction Tolerance / 破壊耐量)**）也存在权衡关系。为了避免损坏而增加吸收浪涌的电路，会增加成本和电路尺寸。功率器件需要在预想的工作条件下，具备器件不会损坏的 **鲁棒性 (Robustness / ロバスト性)**（耐量）。也就是说，改善损耗与破坏耐量的权衡关系也是一项要求。

综上所述，对功率器件所要求的功能，并不仅仅是作为控制电力的开关那么简单。如图1-2所示，为了在紧凑的电路中实现高效的电能转换，需要不断改善损耗、噪声和破坏耐量之间的权衡关系。

## 1-3 功率器件的分类 (Classification of Power Devices / パワーデバイスの分類)

使用进行单纯导通/关断（on/off）动作的开关来实现电流切换，需要两个开关。理想情况下，两个开关无延时地交替进行导通/关断操作，但在现实中很难实现。因此，通常一个开关作为 **有源器件 (Active Element / 能動素子)**，另一个开关作为 **无源器件 (Passive Element / 受動素子)**。有源器件是指带有控制信号输入端子的开关元件，而无源器件则是指没有控制端子的 **二极管 (Diode / ダイオード)**。

因此，功率器件可如表1-1所示，大致分为 **开关元件 (Switching Element / スイッチング素子)** 和 **二极管 (Diode / ダイオード)**。开关元件根据其控制端子的种类，又可分为 **MOS门 (MOS Gate / MOSゲート)**（绝缘栅）和 **结型门 (Junction Gate / 接合ゲート)**。MOS门器件中，控制信号是施加的电压，但在开关瞬间，除了流向MOS电容的位移电流外，几乎没有电流流过。

**表1-1 功率器件的分类**
| | **单极性 (Unipolar / ユニポーラ)** | **双极性 (Bipolar / バイポーラ)** |
| :--- | :--- | :--- |
| **开关元件** | | |
| MOS门 | **功率MOSFET** (Power MOSFET) | **IGBT** |
| 结型门 | **JFET, SIT** | **晶闸管 (Thyristor / サイリスタ)**, **GTO**, **双极性晶体管 (Bipolar Tr)** |
| **二极管** | **SBD (肖特基势垒二极管)** | **pin二极管** (pin Diode) |

而关断状态的稳定维持在结型门中是通过对 **pn结 (pn junction / pn接合)** 施加电压来控制的，这一点与MOS门相同，但由于是向pn结施加电压，因此也被称为 **“电压控制型 (voltage-controlled / 電圧制御型)”** 或 **“电流控制型 (current-controlled / 電流制御型)”**。

此外，在无源器件中，其内部流动的载流子要么是电子，要么是空穴，这被称为 **单极性 (unipolar / ユニポーラ)** 器件。而在有源器件中，电子和空穴两种载流子都对导通做出贡献，这被称为 **双极性 (bipolar / バイポーラ)** 器件。

具有代表性的功率器件，如 **功率MOSFET (Power MOSFET)**、**IGBT** 和 **pin二极管 (pin diode / pinダイオード)** 的断面结构如图1-3所示。功率器件为了在电路下方的布线之间流过电流，通常采用纵向的 **垂直结构 (vertical structure / 縦型構造)**。最新的功率器件采用MOS栅极结构，IGBT在MOSFET的表面形成MOS栅极，其下部为通过在平面栅极中挖沟槽而形成的 **沟槽栅极 (trench gate / トレンチゲート)** 结构。各端子的名称，在MOSFET中是 **源极 (Source / ソース)**、**漏极 (Drain / ドレイン)** 和 **栅极 (Gate / ゲート)**；在IGBT中是 **发射极 (Emitter / エミッタ)**、**集电极 (Collector / コレクタ)** 和栅极；而在pin二极管中则是 **阳极 (Anode / アノード)** 和 **阴极 (Cathode / カソード)**。

IGBT的栅极名称与功率MOSFET略有不同。但在门极方面是相同的，只是由于它是双极性器件，因此端子被称为发射极和集电极。图1-3中的IGBT展示了沟槽栅极结构，但也有使用平面栅极结构的IGBT。pin二极管的端子名称与模型结构相同，分别为阳极和阴极。

在功率MOSFET、IGBT和pin二极管中，一个共同的特点是，它们都具有一个用于在关断状态下保持耐压，同时使漏电流保持在低水平的 **n-漂移层 (n-drift layer / n-ドリフト層)**。这个n-漂移层的厚度和掺杂浓度可以通过调整来设计所需的耐压。

在设计电力电子电路时，需要根据转换功率的大小来选择合适的耐压和器件类型。需要高耐压的功率器件通常施加的电压也很高。为了实现高耐压，器件内部必须有一个能够承受高电压的厚n-漂移层。通常，厚的漂移层会导致电流难以流过，从而增加导通损耗。为了降低这种导通电阻，不仅需要利用电子的单极性导电，还需要利用电子和空穴两种载流子来使漂移层过饱和，这种操作称为 **电导率调制 (conductivity modulation / 導電率変調)**，它可以降低导通损耗。但另一方面，由于开关时需要排出大量的载流子，导致开关时间变长，开关损耗增加。因此，用于大功率转换的高耐压功率器件，往往更容易产生损耗。

如前所述，功率器件的选择取决于转换功率的大小。例如，在转换像个人电脑或照明设备这样的小功率时，电路的小型化是优先考虑的。如图1-4所示，像功率MOSFET这样的单极性器件会在高开关频率下使用。相反，在转换像输配电或铁路、电动汽车这样的大功率时，由于开关过程中容易产生大的损耗，因此像IGBT或晶闸管这样的双极性器件会在较低的开关频率下使用。
