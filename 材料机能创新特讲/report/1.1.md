求解 `ψ(x) = Ce^(ikx) + De^(-ikx)` 中的常数 **C** 和 **D**。

**所需条件（根据您提供的补充幻灯片）：**

    *   `ψ(0) = 0`  (来自式 2-23)
    *   `ψ(a) = 0`  (来自式 2-24)

---

### **推导过程**

我们将使用这两个边界条件来确定 C 和 D 的关系。

**步骤 1：应用第一个边界条件 `ψ(0) = 0`**

将 `x = 0` 代入我们的通解 `ψ(x) = Ce^(ikx) + De^(-ikx)` 中：

`ψ(0) = Ce^(ik*0) + De^(-ik*0)`
`ψ(0) = C * e^0 + D * e^0`
`ψ(0) = C * 1 + D * 1`
`ψ(0) = C + D`

因为我们知道 `ψ(0) = 0`，所以：
**`C + D = 0`**  
这意味着 **`D = -C`**

**步骤 2：将 `D = -C` 代回通解**

现在，我们可以用 `C` 来表示 `D`，从而简化波函数：

`ψ(x) = Ce^(ikx) + (-C)e^(-ikx)`
`ψ(x) = C (e^(ikx) - e^(-ikx))`

这里我们可以使用欧拉公式 `sin(θ) = (e^(iθ) - e^(-iθ)) / 2i`。
根据这个公式，`e^(ikx) - e^(-ikx) = 2i * sin(kx)`。
所以，波函数可以写成：

`ψ(x) = C * (2i * sin(kx))`

为了方便，我们可以令 `A = 2iC` (这里A是一个新的复数常数)，则 `ψ(x) = A sin(kx)`。这证明了指数形式的解和三角函数形式的解是等价的（在前面的解法中，通过 `B=0` 也得到了纯正弦函数的结果）。

**步骤 3：应用第二个边界条件 `ψ(a) = 0`**

现在我们将 `x = a` 代入已简化的波函数 `ψ(x) = A sin(kx)`：

`ψ(a) = A sin(ka)`

因为 `ψ(a) = 0`，所以：
**`A sin(ka) = 0`**

**步骤 4：求解 `ka` 的条件**

这个方程有两种可能：
1.  `A = 0`：如果 `A = 0`，那么 `ψ(x)` 在任何地方都为0。这意味着箱子里没有粒子，这是一个无意义的解（物理上称为“平庸解”）。
2.  `sin(ka) = 0`：为了得到有物理意义的解，必须是这一项为零。

`sin(ka) = 0` 成立的条件是 `ka` 必须是 π 的整数倍：
**`ka = nπ`**  (其中 n = 1, 2, 3, ... )

*   n 不能为0，因为如果 `n=0`，则 `k=0`，`ψ(x)` 再次为0，也是无意义的解。

### **结论**

这个作业要求推导的部分，其核心结论如下：

1.  通过边界条件 `ψ(0) = 0`，我们推导出两个系数的关系为 **`D = -C`**。
2.  通过边界条件 `ψ(a) = 0`，我们推导出量子化条件 **`ka = nπ`** (其中 `n = 1, 2, 3, ...`)。

这两个就是从您给出的“别解法”幻灯片出发，需要推导出的关键结果。常数 `C` 的具体数值需要通过最后一步“归一化”来确定，就像前面解法中求 `A` 的值一样。
