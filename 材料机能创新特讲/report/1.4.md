### **完整推导过程**

**目标：**
从边界条件 **(7-6)** 出发，推导出完整的 **式 (7-12)**，并确定黄色方框中的内容。

**边界条件 (7-6)：**
`ε_in * (∂Φ_in / ∂r) |_(r=a) = ε_out * (∂Φ_out / ∂r) |_(r=a)`

**步骤 1: 计算 `Φ_in` 对 `r` 的偏导数**

`Φ_in` 的表达式为 (式 7-9):
`Φ_in(r, θ) = Σ [C_l * r^l + D_l / r^(l+1)] * P_l(cos θ)`

对 `r` 求偏导：
`∂Φ_in / ∂r = Σ [d/dr (C_l * r^l + D_l * r^(-l-1))] * P_l(cos θ)`
`∂Φ_in / ∂r = Σ [C_l * l * r^(l-1) + D_l * (-l-1) * r^(-l-2)] * P_l(cos θ)`
`∂Φ_in / ∂r = Σ [l * C_l * r^(l-1) - (l+1) * D_l * r^(-l-2)] * P_l(cos θ)`

**步骤 2: 计算 `Φ_out` 对 `r` 的偏导数**

`Φ_out` 的表达式为 (式 7-10):
`Φ_out(r, θ) = Σ [B_l / r^(l+1)] * P_l(cos θ)`

对 `r` 求偏导：
`∂Φ_out / ∂r = Σ [d/dr (B_l * r^(-l-1))] * P_l(cos θ)`
`∂Φ_out / ∂r = Σ [B_l * (-l-1) * r^(-l-2)] * P_l(cos θ)`
`∂Φ_out / ∂r = Σ [-(l+1) * B_l * r^(-l-2)] * P_l(cos θ)`

**步骤 3: 将导数代入边界条件 (7-6)**

我们在边界 `r = a` 处应用条件：
`ε_in * Σ [l*C_l*a^(l-1) - (l+1)*D_l*a^(-l-2)] * P_l(cosθ) = ε_out * Σ [-(l+1)*B_l*a^(-l-2)] * P_l(cosθ)`

由于这个等式对于任意角度 `θ` 都必须成立，所以对于每一个 `l`，勒让德多项式 `P_l(cosθ)` 的系数都必须相等。因此，我们可以去掉求和符号 `Σ` 和 `P_l(cosθ)`：
`ε_in * [l*C_l*a^(l-1) - (l+1)*D_l*a^(-l-2)] = ε_out * [-(l+1)*B_l*a^(-l-2)]`

**步骤 4: 整理方程，确定黄框内容**

现在我们得到了一个完整的方程。让我们把它与幻灯片上的式 (7-12) 对比。
幻灯片上，式 (7-12) 的右边是：`ε_in*l*C_l*a^(l-1) - ε_in*(l+1)*qs^l/a^(l+2)`
*   这正是我们推导出的等式左边，并且将 `D_l = qs^l` (幻灯片中已给出) 代入了。

那么，式 (7-12) 的左边，也就是**黄色方框**里的内容，就必须等于我们推导出的等式右边：
`ε_out * [-(l+1)*B_l*a^(-l-2)]`

整理一下形式，就得到黄框中的答案：
**`-ε_out(l + 1) * B_l / a^(l+2)`**

这就是从边界条件 (7-6) 直接推导出的结果，完美匹配了式 (7-12) 的结构。
