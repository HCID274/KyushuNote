## 1. X射线透射成像

### 1.1 X射线的透射

当X射线穿过样品时，其强度会发生衰减。

[图示：强度为 $I_0$ 的入射X射线穿过厚度为 $t$、线性吸收系数为 $\mu$ 的样品，透射后的X射线强度变为 $I$。]

**透射公式 (朗伯-比尔定律):**
$I = I_0 \exp(-\mu t)$

**其中:**
-   $I_0$: 入射X射线强度
-   $I$: 透射X射线强度
-   $\mu$: 线性吸收系数 (与材料和X射线能量有关)
-   $t$: 样品厚度

**透射强度的依赖关系:**

-   **当样品厚度 $t$ 恒定时**：透射强度主要依赖于线性吸收系数 $\mu$。可以获得样品内部 $\mu$ 的空间分布图像。
-   **当线性吸收系数 $\mu$ 恒定时**：透射强度主要依赖于样品厚度 $t$。可以获得样品的厚度分布图像。

### 1.2 X射线的透射图像示例

-   **主要利用 $\mu$ 差异的图像**：
    -   手部X光片（骨骼和软组织的吸收系数不同）
    -   胸部X光片
    -   工业产品内部探伤
-   **主要利用 $t$ 差异的图像**：
    -   工业管道检测
    -   瓶盖结构
    -   南瓜内部结构

**应用领域**：医疗诊断、产品检验、机场安检等多种领域。

### 1.3 透射图像的局限性

1.  **没有深度分辨率**：
    -   透射图像是三维物体在二维平面上的投影。不同深度的结构会重叠在一起，无法区分其前后位置。
2.  **无法区分具有相同 $\mu t$ 乘积的物质**：
    -   如果两个不同物质A和B，它们的线性吸收系数和厚度的乘积 ($\mu_A t_A = \mu_B t_B$) 恰好相等，那么在透射图像上它们将无法被区分。

**结论**：为了解决这些问题，需要通过 **X射线CT (Computed Tomography)** 进行无损观察，以获得物体的断面图像。

## 2. X射线CT的原理

### 2.1 X射线CT原理 I：离散模型

我们可以将样品内部分为一个个小的单元格（像素或体素），并分别考虑其吸收系数的分布。

[图示：一束X射线 ($I_0$) 穿过一行3个单元格，其吸收系数分别为 $\mu_{11}, \mu_{12}, \mu_{13}$，厚度均为 $t$。]

-   穿过第1个单元格后的强度 $I_{11}$:
    $I_{11} = I_0 \exp(-\mu_{11} t)$
-   穿过第2个单元格后的强度 $I_{12}$:
    $I_{12} = I_{11} \exp(-\mu_{12} t)$
-   穿过第3个单元格后的强度 $I_{13}$:
    $I_{13} = I_{12} \exp(-\mu_{13} t)$

因此，穿过整行单元格后的总强度为：
$I_{13} = I_0 \exp(-\mu_{11} t) \times \exp(-\mu_{12} t) \times \exp(-\mu_{13} t) = I_0 \exp(-(\mu_{11} + \mu_{12} + \mu_{13})t)$

这表明，沿X射线路径的线性吸收系数 $\mu$ 是可以**累加**的。

### 2.2 X射线CT原理 II：投影与正弦图 (Sinogram)

通过从多个不同角度对样品进行X射线照射，可以获得一系列的投影数据。

[图示：一个 3x3 的样品，每个单元格有不同的 $\mu$ 值。分别从 0°, 90°, 180°, 270° 四个方向进行投影，得到每行/每列的 $\mu$ 值总和。]

将每个角度下探测器上每个像素的强度数据收集起来，就构成了**正弦图 (Sinogram)**。

**CT重建 (Reconstruction)** 的核心任务就是：从获取的投影数据（正弦图）出发，通过计算求解出样品内部原始的 $\mu$ 分布图（即CT图像）。

> **CT**: Computed Tomography，即通过计算得到的断面图像。

### 2.3 断面像的重建方法 I：反投影法 (Back Projection)

这是一种直观但不够精确的重建方法。它将正弦图中的每个投影数据（线积分值）沿其原始的投影方向“涂抹”回图像空间。

[图示：将 0°, 90°, 180°, 270° 四个方向的投影数据直接叠加到一个空的图像矩阵上。]

-   将所有角度的投影数据叠加后，再除以投影数量。
-   **结果分析**：
    -   重建图像的**趋势**与原始分布大致相符。
    -   **存在问题**：
        1.  存在背景偏移（理想的0值区域不为0）。
        2.  不同区域的数值比例与原始图像不同。
        3.  图像模糊，尤其是在中心区域，因为中心点被叠加的次数最多。

### 2.4 断面像的重建方法 II：滤波反投影法 (Filtered Back-Projection, FBP)

FBP法是目前CT重建中最常用、最高效的方法。它在反投影之前，先对投影数据进行一次**滤波**操作。

**流程**：`投影数据` -> `与滤波器函数进行卷积` -> `反投影`

-   **滤波器的作用**：
    -   通过一个**高通滤波器**来校正反投影法导致的图像模糊问题，特别是减少中心区域的过度叠加效应。
    -   理论上，可以使用 **Ramachandran-Lakshminarayanan (RL) 滤波器**，但它会放大噪声。
    -   在实际应用中，通常使用 **Shepp-Logan (SL) 滤波器** 或类似的滤波器，它能在增强图像细节的同时有效抑制噪声。
-   **滤波器的选择**：
    -   不同的滤波器会导致重建图像的画质有所不同。
    -   在医疗CT中，会根据不同的检查部位（如头部、腹部）选择最优化的滤波器。

## 3. X射线CT的装置与方法

### 3.1 X射线CT装置的基本构成

[图示：X射线CT装置示意图，包括光源、(单色器)、样品旋转台和图像探测器。]

-   **光源 (X-ray Source)**: 产生X射线。
-   **(单色器 Monochromator)**: (可选) 用于选择特定能量的X射线。
-   **样品旋转台 (Stage)**: 用于从不同角度旋转样品。
-   **图像探测器 (Detector)**: 记录穿过样品的X射线强度。

**扫描模式**:
| 扫描方式 | 概要 | 优点 | 主要用途 |
| :--- | :--- | :--- | :--- |
| **连续扫描** | 在样品连续旋转的同时进行连续拍摄 | 高速 | 产品检查、医疗 |
| **步进扫描** | 每旋转一个固定角度后停止并拍摄 | 高精细 | 精密测量 |

### 3.2 光源的种类与特征

| 特性 | 实验室X射线源 | 同步辐射光源 |
| :--- | :--- | :--- |
| **原理** | 电子撞击金属靶产生X射线 | 磁场使高能电子束偏转产生电磁辐射 |
| **发散角** | 大 | 极小（高准直性） |
| **强度/亮度** | 较低 | **高出10,000倍以上** |
| **尺寸** | 数米 | 数百米至数公里 |
| **成本** | 数百万日元 | 数百亿日元 |
| **能量谱** | 连续谱+特征谱 | 宽能带连续谱 |

> **结论**: 为了获得更高的分辨率，需要**亮度极高**的X射线源，因此**同步辐射光**是不可或缺的。

### 3.3 X射线图像探测器的种类与特征

| 探测器类型 | 探测原理 | 能量分辨率 | 像素尺寸 | 观察视野 |
| :--- | :--- | :--- | :--- | :--- |
| **X射线影像增强器 (I.I.)** | X射线->电子->增强->可见光 | 无 | ~50 µm | >100 mm |
| **平板探测器 (FPD)** | X射线->闪烁体->可见光->光电二极管 | 无 | ~25 µm | >50 mm |
| **闪烁体+CCD/CMOS (镜头耦合)** | X射线->闪烁体->可见光->镜头->CCD/CMOS | 无 | <1 µm | <2 mm |
| **闪烁体+CCD/CMOS (光纤耦合)** | X射线->闪烁体->可见光->光纤->CCD/CMOS | 无 | <10 µm | ~15 mm |
| **半导体探测器 (光子计数型)**| X射线在半导体内直接产生电子-空穴对 | **有** | ~100 µm | >50 mm |

## 4. 数据采集与分析流程

### 4.1 一般的CT测量流程 (步进扫描)

1.  **移出样品** -> **采集背景图像** (至少20张以上，用于校正)。
2.  **放入样品**。
3.  **开始采集投影**:
    -   采集一张透射图像。
    -   将样品旋转一个固定角度。
    -   重复上述过程，直到完成180°或360°的扫描 (例如，采集500个投影)。
4.  **再次移出样品** -> **采集背景图像** (用于校正系统漂移)。

### 4.2 一般的数据分析流程

1.  **背景校正**: `(原始投影 - 暗场) / (背景 - 暗场)`，然后取对数，得到线性吸收系数的积分值。
2.  **生成Sinogram**: 将所有投影的同一行数据排列在一起，形成该断层的正弦图。
3.  **FBP重建**: 使用SL滤波器对Sinogram进行滤波，然后通过GPU加速的反投影算法重建出断面图像。
4.  **伪DICOM化**: 将一系列的断面图像（RAW data）转换为医学图像标准格式DICOM。
5.  **三维可视化**: 使用Volume Rendering软件（如ImageJ, Fiji, Osirix等）对DICOM数据进行三维重建和显示。

## 5. 利用同步辐射光的先进成像技术

同步辐射光具有**大强度、高准直性（平行光）、单色性**等优点，如同激光一样，可实现远超传统X射线CT的高精细观察。

### 5.1 高空间分辨率测量 (Micro-CT)

| 方法 | 平行光束照射型 | 扫描型X射线显微镜 | 成像型X射线显微镜 |
| :--- | :--- | :--- | :--- |
| **概要** | 平行光束 + 高分辨率探测器 | 将聚焦后的X射线束在样品上扫描 | 使用X射线光学元件（如反射镜）放大图像 |
| **观察视野** | ~3 mm | ~200 µm | <100 µm |
| **空间分辨率** | ~1 µm | <0.5 µm | **<0.1 µm** |
| **测量时间** | 短 | 长 | 中 |
| **其他** | 可进行大视野成像 | 可进行多物理量分析（元素、结晶性等） | 需要高亮度线源 |

**示例**:
-   **微体化石（星砂）**: 测量时间100秒，空间分辨率~2 µm。
-   **冰淇淋的微观结构**: 在-40℃下观察到冰晶、糖和空气隙的分布，最小空隙~2 µm。

### 5.2 高时间分辨率测量 (高速CT / 4D-CT)

使用高速相机，可以实现对动态过程的超快成像。

**示例**:
-   **水滴下落**: 曝光时间30 µs，帧率5000 fps，可以清晰捕捉水滴与水面碰撞的瞬间。
-   **高速CT (4D-CT)**: 通过高速旋转样品和高速相机，可以在50 ms内完成一次CT扫描，实现对物体内部结构动态变化的三维（+时间）观察。

### 5.3 高密度分辨率测量 (相位成像)

-   **原理**:
    -   传统CT利用**吸收衬度**（振幅变化）。
    -   对于软组织等轻元素构成的样品，吸收衬度非常弱。
    -   X射线穿过物体时，不仅振幅会衰减，**相位**也会发生改变（位相移）。
    -   对于轻元素，相位变化比吸收变化**敏感1000倍以上**。
    -   通过检测相位变化，可以对软组织进行高灵敏度的观察。

-   **相位检测方法**:
| 方法 | 概要 | 灵敏度 | 密度范围 |
| :--- | :--- | :--- | :--- |
| **X射线干涉法** | 利用晶体干涉仪检测相位，**灵敏度最高** | ◎ | 窄 |
| **衍射增强成像 (DEI)** | 利用晶体的衍射现象检测折射角 | ○ | 宽 |
| **塔尔博干涉法** | 利用光栅的塔尔博效应进行检测 | △ | 中 |
| **传播法** | 利用菲涅尔衍射效应进行检测 | ○ | 宽 |

**示例**:
-   **阿尔兹海默症模型鼠大脑**: 使用晶体干涉法，可以清晰地观察到密度差极小（< 数 mg/cm³）的β-淀粉样蛋白斑块，并追踪其随年龄增长的变化。
-   **南极冰芯中的空气水合物**: 作为“远古大气的时光胶囊”，其分布和形态可以用来推断古地球环境。相位成像可以无损地观察其三维分布。

---

## 6. 总结

1.  **X射线CT** 是一种利用X射线的高穿透性，无损地三维观察样品内部密度分布的方法。
2.  重建一幅CT图像至少需要 **180度** 范围内的投影数据。
3.  **同步辐射光** 具有 **(1) 大强度、(2) 单色性、(3) 高准直性（平行光）** 的特点，与传统的X射线CT相比，可以进行各种高精细的观察。
