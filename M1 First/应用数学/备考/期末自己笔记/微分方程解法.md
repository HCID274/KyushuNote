### **常系数线性微分方程 (Linear Differential Equations with Constant Coefficients)**

常系数线性微分方程是一类形式为
$$ a_n y^{(n)} + a_{n-1} y^{(n-1)} + \cdots + a_1 y' + a_0 y = f(x) $$
的微分方程，其中 $a_0, a_1, \ldots, a_n$ 是常数。

当 $f(x) = 0$ 时，该方程称为**齐次 (homogeneous)** 方程。
当 $f(x) \neq 0$ 时，该方程称为**非齐次 (non-homogeneous)** 方程。

---

### **第一部分：齐次线性微分方程的解法**

对于二阶齐次线性微分方程
$$ ay'' + by' + cy = 0 $$
我们假设解的形式为 $y = e^{\lambda x}$。将其代入方程，我们得到**特征方程 (characteristic equation)**：
$$ a\lambda^2 + b\lambda + c = 0 $$
特征方程的解 $\lambda$ 决定了微分方程的通解。

#### **情况一：两个不相等的实数解 (Distinct Real Roots)**

如果特征方程的判别式 $\Delta = b^2 - 4ac > 0$，则方程有两个不相等的实数解 $\lambda_1$ 和 $\lambda_2$。
通解为：
$$ y(x) = c_1 e^{\lambda_1 x} + c_2 e^{\lambda_2 x} $$
其中 $c_1$ 和 $c_2$ 是任意常数。

#### **情况二：两个相等的实数解 (Repeated Real Roots)**

如果特征方程的判别式 $\Delta = b^2 - 4ac = 0$，则方程有一个重根 $\lambda_1 = \lambda_2 = \lambda$。
通解为：
$$ y(x) = (c_1 + c_2 x) e^{\lambda x} $$
其中 $c_1$ 和 $c_2$ 是任意常数。

#### **情况三：一对共轭复数解 (Complex Conjugate Roots)**

如果特征方程的判别式 $\Delta = b^2 - 4ac < 0$，则方程有一对共轭复数解 $\lambda = \alpha \pm i\beta$，其中 $\alpha, \beta$ 是实数。
通解为：
$$ y(x) = e^{\alpha x} (c_1 \cos(\beta x) + c_2 \sin(\beta x)) $$
其中 $c_1$ 和 $c_2$ 是任意常数。

---

### **第二部分：非齐次线性微分方程的解法**

对于非齐次线性微分方程
$$ ay'' + by' + cy = f(x) $$
其通解 $y(x)$ 是对应的齐次方程的通解 $y_h(x)$ 和非齐次方程的一个**特解 (particular solution)** $y_p(x)$ 的和。
$$ y(x) = y_h(x) + y_p(x) $$
求解特解 $y_p(x)$ 的常用方法是**待定系数法 (Method of Undetermined Coefficients)**。该方法适用于 $f(x)$ 具有特定形式（如多项式、指数函数、正弦或余弦函数及其组合）的情况。

#### **待定系数法**

1.  **根据 $f(x)$ 的形式猜测 $y_p(x)$ 的形式**:
    *   如果 $f(x)$ 是一个 $n$ 次多项式，则猜测 $y_p(x)$ 是一个 $n$ 次多项式：
        $$ y_p(x) = A_n x^n + \cdots + A_1 x + A_0 $$
    *   如果 $f(x) = Ae^{kx}$，则猜测 $y_p(x) = Be^{kx}$。
    *   如果 $f(x) = A\cos(kx) + B\sin(kx)$，则猜测 $y_p(x) = C\cos(kx) + D\sin(kx)$。

2.  **修正规则**: 如果猜测的 $y_p(x)$ 中的任何一项已经是齐次方程通解 $y_h(x)$ 的一部分，则需要将猜测的 $y_p(x)$ 乘以 $x$（如果仍然是 $y_h(x)$ 的一部分，则继续乘以 $x$），直到不再有任何项是 $y_h(x)$ 的解。

3.  **求解系数**: 将猜测的 $y_p(x)$ 及其导数代入原非齐次方程，然后通过比较等式两边的同类项系数来确定待定系数。

#### **叠加原理 (Superposition Principle)**

如果 $f(x)$ 是几个不同形式函数的和，例如 $f(x) = f_1(x) + f_2(x)$，可以分别求出对应于 $f_1(x)$ 和 $f_2(x)$ 的特解 $y_{p1}(x)$ 和 $y_{p2}(x)$，那么原方程的特解就是这两个特解之和：
$$ y_p(x) = y_{p1}(x) + y_{p2}(x) $$

---

### **示例方程解析**

#### **例1: $y'' - 4y' - 5y = 5x + 6$**

1.  **求解齐次方程 $y'' - 4y' - 5y = 0$**:
    *   特征方程: $\lambda^2 - 4\lambda - 5 = 0 \implies (\lambda-5)(\lambda+1) = 0$
    *   特征根: $\lambda_1 = 5, \lambda_2 = -1$ (两个不相等的实数解)
    *   齐次解: $y_h(x) = c_1 e^{5x} + c_2 e^{-x}$

2.  **求解特解 $y_p(x)$**:
    *   非齐次项 $f(x) = 5x + 6$ 是一次多项式。
    *   猜测特解形式: $y_p(x) = Ax + B$
    *   求导: $y_p'(x) = A, y_p''(x) = 0$
    *   代入原方程: $0 - 4(A) - 5(Ax + B) = 5x + 6 \implies -5Ax - (4A + 5B) = 5x + 6$
    *   比较系数:
        *   $-5A = 5 \implies A = -1$
        *   $-(4A + 5B) = 6 \implies -(-4 + 5B) = 6 \implies 4 - 5B = 6 \implies 5B = -2 \implies B = -2/5$
    *   特解: $y_p(x) = -x - 2/5$

3.  **通解**:
    $$ y(x) = y_h(x) + y_p(x) = c_1 e^{5x} + c_2 e^{-x} - x - 2/5 $$

#### **例2: $y'' + 4y = \sin(3x)$**

1.  **求解齐次方程 $y'' + 4y = 0$**:
    *   特征方程: $\lambda^2 + 4 = 0$
    *   特征根: $\lambda = \pm 2i$ (共轭复数解, $\alpha=0, \beta=2$)
    *   齐次解: $y_h(x) = c_1 \cos(2x) + c_2 \sin(2x)$

2.  **求解特解 $y_p(x)$**:
    *   非齐次项 $f(x) = \sin(3x)$。
    *   猜测特解形式: $y_p(x) = A\cos(3x) + B\sin(3x)$
    *   求导: $y_p'(x) = -3A\sin(3x) + 3B\cos(3x), y_p''(x) = -9A\cos(3x) - 9B\sin(3x)$
    *   代入原方程: $(-9A\cos(3x) - 9B\sin(3x)) + 4(A\cos(3x) + B\sin(3x)) = \sin(3x)$
    *   整理: $(-5A)\cos(3x) + (-5B)\sin(3x) = 0\cdot\cos(3x) + 1\cdot\sin(3x)$
    *   比较系数:
        *   $-5A = 0 \implies A = 0$
        *   $-5B = 1 \implies B = -1/5$
    *   特解: $y_p(x) = -\frac{1}{5}\sin(3x)$

3.  **通解**:
    $$ y(x) = y_h(x) + y_p(x) = c_1 \cos(2x) + c_2 \sin(2x) - \frac{1}{5}\sin(3x) $$

#### **例3: $y'' - 3y' - 4y = \sin(x) + x^3$**

1.  **求解齐次方程 $y'' - 3y' - 4y = 0$**:
    *   特征方程: $\lambda^2 - 3\lambda - 4 = 0 \implies (\lambda-4)(\lambda+1) = 0$
    *   特征根: $\lambda_1 = 4, \lambda_2 = -1$
    *   齐次解: $y_h(x) = c_1 e^{4x} + c_2 e^{-x}$

2.  **求解特解 $y_p(x)$** (使用叠加原理):
    *   **Part A**: 求解 $y'' - 3y' - 4y = \sin(x)$ 的特解 $y_{p1}(x)$。
        *   猜测 $y_{p1}(x) = A\cos(x) + B\sin(x)$
        *   代入并求解系数得到: $y_{p1}(x) = \frac{3}{26}\cos(x) - \frac{5}{26}\sin(x)$
    *   **Part B**: 求解 $y'' - 3y' - 4y = x^3$ 的特解 $y_{p2}(x)$。
        *   猜测 $y_{p2}(x) = Cx^3 + Dx^2 + Ex + F$
        *   代入并求解系数得到: $y_{p2}(x) = -\frac{1}{4}x^3 + \frac{9}{16}x^2 - \frac{21}{32}x + \frac{45}{128}$

3.  **通解**:
    $$ y(x) = y_h(x) + y_{p1}(x) + y_{p2}(x) $$
    $$ y(x) = c_1 e^{4x} + c_2 e^{-x} + \frac{3}{26}\cos(x) - \frac{5}{26}\sin(x) - \frac{1}{4}x^3 + \frac{9}{16}x^2 - \frac{21}{32}x + \frac{45}{128} $$
