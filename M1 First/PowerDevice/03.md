# 3. 二极管 (Diode / ダイオード)

## 3-1 基本结构与工作原理 (Basic Structure and Operation / 基本構造と動作)

在介绍作为开关元件的功率MOSFET和IGBT之前，我们先来说明一下结构更为简单的两端元件——**二极管 (Diode / ダイオード)**。如表1-1所示，二极管可分为 **单极性 (Unipolar / ユニポーラ)** 的 **肖特基势垒二极管 (Schottky Barrier Diode / ショットキーバリアダイオード, SBD)** 和 **双极性 (Bipolar / バイポーラ)** 的 **pin二极管 (pin Diode / pinダイオード)** 两大类。如图3-1(a)所示，SBD的结构是在n-漂移层和阳极电极的界面处形成肖特基接触。通过这种 **肖特基势垒 (Schottky Barrier / ショットキー接合)** 的电势垒，当对阳极施加正电压（正向偏置）时，漂移层的电子会向阳极电极移动，从而实现正向导通。当对阳极电极施加负电压（反向偏置）时，电流被电势垒阻挡，不会流动。此时，电场由从肖特基接触延伸出的耗尽层来维持。

另一方面，表面形成p-阳极层的pin二极管，其结构如图3-1(b)所示。当施加正向电压时，空穴从p-阳极层注入，电子从n-阴极层注入，p-阳极层和n-漂移层结处的耗尽层收缩，电流开始流动。当施加反向电压时，耗尽层从p-阳极层和n-漂移层的结向n-阴极层方向扩展，电场由扩展的耗尽层维持。

**正向特性 (Forward Characteristics / 順方向特性)** 在图3-2的示意图中有所展示，根据二极管的种类有很大不同。pn结的电势垒较高，而肖特基结的电势垒较低，因此在低正向电压下，SBD更容易导通。然而，由于单极性工作原理，其电阻较高，随着电流增大，pin二极管的导通电压会变得更低。

当反向电压增加时，漂移层内的电场会增强，最终发生雪崩击穿。该电压即为耐压。在正向偏置时，前端所述的n-漂移层的浓度和厚度是根据耐压设计的。而在反向偏置时，由于pn结的电势垒高于肖特基结，所以pin二极管的微小反向漏电流比SBD更小。此外，由于肖特基势垒会随着施加的电压而降低，即存在 **肖特基势垒降低效应 (Schottky Barrier Lowering / 鏡像効果)**，SBD的耐压趋向于在反向漏电流开始增加之前就达到极限。

我们来阐述决定SBD和pin二极管特性的参数。首先，SBD的 **正向导通电压 (Forward On-voltage / 順方向オン電圧)** $V_{FSBD}$ 是肖特基结上施加的电压 $V_{SB}$ 和漂移层电压降 $V_{drift}$ 的和。

$$
V_{FSBD} = V_{SB} + V_{drift} \quad (11)
$$

此时，$V_{SB}$ 与正向电流密度 $J_F$ 的关系为：

$$
J_F = AT^2\exp(-\frac{q\phi_B}{k_B T})\{\exp(\frac{qV_{SB}}{k_B T}) - 1\} \quad (12)
$$

其中，A是理查德森常数，T是绝对温度，$\phi_B$ 是肖特基势垒高度，$k_B$ 是玻尔兹曼常数。而漂移层电压降 $V_{drift}$ 由漂移层电阻 $R_{on}$ 和正向电流密度 $J_F$ 决定。

$$
V_{drift} = R_{on} J_F = \frac{t_{drift}}{q N_{drift} \mu_n} J_F \quad (13)
$$

正如在功率器件基本设计中所述，漂移层电阻与耐压之间存在权衡关系。

![图3-1 (a)肖特基势垒二极管(SBD)和(b)pin二极管的断面构造和能带图](figure_3-1.png)

在高正向电压下，pin二极管由于其双极性工作原理，通过电导率调制使漂移层电阻降低，因此其导通电压低于SBD。因此，Si SBD一般用于200V以下，200V以上则使用pin二极管。

![图3-2 SBD和pin二极管的I-V特性](figure_3-2.png)

从式(12)可以看出，为了降低逆向漏电流，需要一个大的 **肖特基势垒高度 (Schottky Barrier Height / ショットキー障壁の高さ)** $\phi_B$。但是，从式(12)可以看出，如果 $\phi_B$ 增大，漏电流会减小，但导通时的 $V_{SB}$ 会增大，导通电压也会升高。也就是说，SBD的正向电压和反向漏电流之间存在权衡关系，这可以通过阳极电极的金属种类来调整。另外，为了在高电压施加时抑制漏电流的增加，如图3-3所示，采用了 **结势垒控制肖特基 (Junction Barrier Controlled Schottky, JBS)** 结构或 **沟槽肖特基 (Trench Schottky)** 结构。这些结构通过在阳极金属下方形成p层或多晶硅层，来遮蔽施加在肖特基势垒上的电场，从而抑制高电压施加时因镜面效应导致的势垒降低和漏电流增加。

接下来，我们阐述pin二极管的特性。pin二极管的导通电压 $V_{Fpin}$ 是p-阳极层和n-漂移层结上施加的电压 $V_{pn}$、漂移层电压降 $V_{drift}$、以及n-漂移层和n-阴极层结上施加的电压 $V_{nn}$ 之和。

$$
V_{Fpin} = V_{pn} + V_{drift} + V_{nn} \quad (14)
$$

其中，$V_{pn}$ 和 $V_{nn}$ 的和取决于漂移层内的载流子浓度。

$$
V_{pn} + V_{nn} = \frac{k_B T}{q} \ln(\frac{p_n p_i}{n_i^2}) \quad (15)
$$

其中，$p_n$ 是阳极侧的载流子浓度，$p_i$ 是阴极侧的载流子浓度，$n_i$ 是本征载流子浓度。在高注入状态下，漂移层接近电中性，电子和空穴浓度几乎相等，且载流子产生可忽略不计。此时，p-阳极层和n-阴极层为多数载流子源，电流接近于扩散电流。此时的载流子分布 $p(x)$ 为：

$$
p(x) = \frac{J_F}{2qD_a} \frac{\sinh((L_a - x)/L_a)}{\cosh(d/L_a)} - B \frac{\sinh(x/L_a)}{\sinh(d/L_a)} \quad (16)
$$

其中，$L_a$ 是扩散长度，x是位置，d是位置，$B$ 是一个常数。$L_a$ 定义如下，$\tau$ 是寿命。

$$
L_a = \sqrt{D_a \tau} = \sqrt{\frac{2D_n D_p}{D_n + D_p}\tau} \quad (17)
$$

其中，$D_n$ 和 $D_p$ 分别是电子和空穴的扩散系数。使用式(16)并假设漂移层厚度为 $200\mu m$，可以计算出室温下的载流子分布，如图3-4所示。载流子浓度分布左右不对称，这是由于电子和空穴的迁移率不同造成的。如式(16)所示，随着电流的增加，载流子浓度也会增加。漂移层的电压降 $V_{drift}$ 在正向导通时为：

比例关系，它与载流子密度成反比。因此，正向导通电压与电流成反比。但如式(16)所示，实际的函数形式比上述的更复杂，实际上，正向导通电压随电流增加而单调增加。

![图3-4 正向偏置下漂移层内的载流子分布](figure_3-4.png)

如前所述，SBD的正向导通电压与漂移层电阻成正比，而漂移层电阻又与正向电流无关，因此从式(13)可以看出，导通电压与正向电流成正比增加。与此相对，pin二极管由于其双极性工作原理，抑制了 $V_{drift}$ 的增加。因此，当正向电流较大时，可以获得比SBD更低的导通电压。此外，式(17)表明，扩散长度越长，载流子寿命也越长。当扩散长度长于漂移层厚度时，可以认为载流子在漂移层中的再结合可以忽略不计。此时，漂移层中心的载流子密度降低。这表明漂移层对高耐压器件的影响很大，因为其厚度较厚，而载流子再结合的影响也很大。

## 3-2 反向恢复特性 (Reverse Recovery Characteristics / リカバリー特性)

二极管通过施加电压来切换允许电流流过的导通状态和不允许电流流过的关断状态。通常，在电力电子电路中，二极管与开关元件和负载一起配置。当开关元件从关断切换到导通时，施加在二极管上的电压会发生变化，电流路径也会随之改变。此时，二极管上施加的电压变化与电流切换的时机协同工作的操作，被称为 **二极管恢复动作 (Diode Recovery Operation / ダイオードのリカバリー動作)**。从导通状态（正向偏置）切换到关断状态（反向偏置）的动作称为 **逆向恢复 (Reverse Recovery / 逆回復)**，而从反向方向切换到正向方向的动作称为 **正向恢复 (Forward Recovery / 順回復)**。

在逆向恢复时，在导通状态下注入到漂移层中的载流子，需要施加反向电压，并在耗尽层扩展的同时被扫出。因此，需要花费一定的时间才能将这些载流子扫出，在此期间会产生过度的电流，从而导致损耗。另一方面，在正向恢复时，耗尽层消失，载流子注入到漂移层中，但几乎不产生过电压。因此，二极管的特性主要关注逆向恢复时的特性。

通常，电力电子电路中的负载是电感性负载，如电机等。因此，为了评估其特性，使用如图3-5所示的 **电感负载 (Inductive Load / 誘導性負荷)**（L负载）与二极管和开关元件连接的电路。当开关元件导通时，电流从电源流经电感负载和开关元件（路径A）。当开关元件关断时，路径B被切断，电流从直流电源经电感负载和二极管流动，此时电感负载中储存的能量被释放。此时，施加在二极管上的电压从反向偏置切换到正向偏置。

![图3-5 L负载开关电路](figure_3-5.png)

逆向恢复时的电压和电流变化如图3-6所示。当开关元件导通时，流过二极管的电流逐渐减少。之后，二极管内部的载流子被扫出，耗尽层扩展，电流开始沿反向流动。当二极管内的载流子完全耗尽并变为关断状态后，反向电流变为零。但是，受电感负载的影响，电流和电压的变化被延迟，电压变为反向偏置并增加。

![图3-6 二极管逆向恢复波形](figure_3-6.png)

在逆向恢复期间，会流过比稳态时更大的反向电流，并施加高电压，从而产生损耗。此时的损耗被称为 **逆向恢复损耗 (Reverse Recovery Loss / リカバリー損失)**。评估恢复特性所需的参数包括：从电流变为反向到恢复所需的时间（**逆向恢复时间 (Reverse Recovery Time / リカバリー時間)**）$t_{rr}$，峰值反向恢复电流（**反向恢复电流 (Reverse Recovery Current / リカバリー電流)**）$I_{rr}$，以及对逆向恢复时间内的电流进行积分得到的电荷（**逆向恢复电荷 (Reverse Recovery Charge / リカバリーチャージ)**）$Q_{rr}$。这些参数都被用作衡量恢复损耗大小的指标。

$Q_{rr}$ 由导通状态下存在于漂移层中的电荷量决定。因此，在SBD中，它仅由漂移层厚度和浓度决定，而在pin二极管中，它由注入的电子和空穴的量决定，因此pin二极管的 $Q_{rr}$ 比SBD大得多，且逆向恢复损耗也更大。

为了降低pin二极管的导通电压 $V_{Fpin}$，需要提高漂移层内的载流子密度。然而，为了注入大量载流子，需要时间，这会导致产生大的 $I_{rr}$。因此，pin二极管的 $V_{Fpin}$ 和 $E_{rr}$（恢复损耗）之间存在权衡关系。改善这一权衡关系是pin二极管开发的核心课题之一。

二极管开发中的另一个重要性能是低噪声。由于恢复损耗与 $I_{rr}$ 成正比，为了减少损耗，希望尽快结束恢复。然而，如果急剧地改变电流，电压变化和寄生电感的乘积，即浪涌电压会施加在二极管上，成为噪声的来源。因此，使用 **软恢复系数 (Softness Factor / ソフトネス指数)** S (= $t_b/t_a$) 作为低噪声的指标。该指数是逆向恢复后半段与前半段时间的比值。指数越大，即恢复越平缓，噪声越小。S（$t_a$ 短）小的、急剧的电压变化的恢复被称为 **硬恢复 (Hard Recovery / ハードリカバリー)**。

## 3-3 结构的发展 (Structural Evolution / 構造の進展)

改善pin二极管中 $V_{Fpin}$ 和 $E_{rr}$ 权衡关系的有效手段是减薄漂移层的厚度。通过减薄漂移层，由于漂移层电阻的下降，$V_{Fpin}$ 会降低。同时，由于排出的载流子减少，$E_{rr}$ 也会降低。但是，伴随漂移层减薄而来的耐压下降会加速，从而导致硬恢复。

为了在维持软恢复的同时改善这种权衡关系，通常采用在阴极侧设置n-缓冲层的结构，该缓冲层比n-漂移层的电阻更低。如图3-7所示，通过设置缓冲层，即使在施加高反向电压时，耗尽层也不会到达阴极，从而可以抑制急剧的电流变化，并保持软恢复，缩短 $t_a$ 以实现软恢复。

![图3-7 通过引入p-缓冲层使二极管更薄](figure_3-7.png)

为了进一步改善 $V_{pin}$ 和 $E_{rr}$ 的权衡关系，需要对控制二极管特性的过剩载流子量进行控制。如图3-8所示，通过重金属扩散或电子束/质子束照射，在漂移层内局部形成复合中心。由此，可以保持导通所需的载流子，同时缩短恢复时间。通过重金属扩散或电子束照射，在整个漂移层中形成复合中心，而质子束或氦照射则在与照射能量相应的深度形成复合中心。通过形成局部复合中心，可以缩短载流子寿命，从而缩短再结合所需的时间。虽然载流子浓度降低，导致 $V_{pin}$ 增加，但通过进行适当的控制，可以获得比 $E_{rr}$ 降低效果更大的改进。但是，复合中心在常温下也会工作，导致反向漏电流增加。高温下漏电流增加，由漏电流引起的发热会导致漏电流进一步增加，从而引发热失控。形成复合中心的位置和密度根据二极管的种类和条件而异。因此，在考虑寿命控制的工艺条件时，需要考虑工作保证温度。

![图3-8 通过寿命控制的恢复改进](figure_3-8.png)

近年来，作为上述方法的补充，还提出了控制从阳极和阴极注入载流量的方法。图3-9(a)所示的 **SPEED (Self-adjusting P-Emitter Efficiency Diode)** 结构通过在阳极侧设置低浓度p层和高浓度p层，从阳极注入空穴。在图(b)的 **SC (Schottky Controlled) diode** 结构中，通过在从阳极注入的空穴之间设置肖特基接触，使电子从阴极侧注入，从而实现注入控制和高速化。图(c)所示的 **CIBH** 结构通过在n-缓冲层上部形成p层，从阴极注入电子。图(d)的 **RFC** 结构通过在n-缓冲层上部形成p层，同时注入电子和空穴。在RFC结构中，当恢复时，从p层注入的空穴与电子再结合，从而实现软恢复和高速化。

![图3-9 各种pin二极管的改进结构](figure_3-9.png)

通过这些改进措施，在确立 $V_{Fpin}$ 和 $E_{rr}$ 的权衡关系以及与噪声之间的权衡关系的同时，性能得到系统性的提升。
