# 6 宽禁带半导体器件 (Wide-Bandgap Semiconductor Devices / ワイドバンドギャップ半導体デバイス)

## 6-1 宽禁带半导体器件的定位 (Positioning of Wide-Bandgap Semiconductor Devices / ワイドバンドギャップ半導体デバイスの位置づけ)

采用 **硅 (Silicon / Si)** 材料的功率器件已经实用化，至今已过了约40年。在此期间，Si器件的性能被逐步推向其材料的理论性能极限。在这种情况下，作为今后进一步飞跃性地提升性能，打破其极限的手段，采用耐压性能优于Si的 **宽禁带半导体 (Wide-Bandgap Semiconductor / ワイドバンドギャップ半導体)** 的器件正受到越来越多的关注。

如基本设计部分所述，功率器件的重要性能指标之一是 **导通电阻 (On-resistance / オン抵抗)** 与 **耐压 (Withstand Voltage / 耐圧)** 之间的权衡关系。材料的物性决定了其极限，导通电阻的极限值与材料 **临界电场 (Critical Electric Field / 臨界電界)** 的三次方成反比。因此，与Si相比，具有更高临界电场的宽禁带半导体，有望实现飞跃性的低导通电阻。图6-1展示了Si器件和宽禁带半导体器件的电场分布示意图。耐压由能够承受的电荷量，即电场分布在临界电场以下的面积决定。电场分布的斜率是 **空乏层 (Depletion Layer / 空乏層)** 中的净不纯物浓度，因此，如果空乏层的厚度，即漂移层的厚度相同，耐压也就相同。如果临界电场高，即使在相同的耐压下，也可以提高不纯物浓度，从而获得更低的导通电阻。

![图 6-1 Si器件和宽禁带半导体器件的电场分布示意图](figure_6-1.png)

此外，导通电阻的大小与产生电子-空穴对所需的能量大小有关，如果能量大，则更难发生 **雪崩击穿 (Avalanche Breakdown / アバランシェ降伏)**。因此，宽禁带半导体具有高临界电场。正因如此，宽禁带半导体器件与Si器件相比，低导通电阻值得期待。

作为可用于功率器件的宽禁带半导体材料，具有比Si高10倍以上临界电场的 **碳化硅 (Silicon Carbide / SiC / 炭化ケイ素)** 和 **氮化镓 (Gallium Nitride / GaN / 窒化ガリウム)** 受到了关注。图6-2展示了作为耐压极限的导通电阻。Si的耐压极限约为1/200，而GaN的耐压极限约为1/2400。正如所预期的那样，可以实现飞跃性的低导通电阻，因此，宽禁带半导体器件作为下一代功率器件备受瞩目。

![图 6-2 Si, SiC, GaN的导通电阻-耐压权衡材料极限](figure_6-2.png) ![图 6-3 宽禁带半导体器件的目标](figure_6-3.png)

飞跃性的性能提升，不仅仅是替换Si功率器件，还为迄今为止Si功率器件无法实现的动作领域和应用领域开辟了可能性。因此，如图6-3所示，对高耐压、大容量以及高频应用的适应性正在扩大。耐高压、大容量的SiC，有望取代Si-IGBT或晶闸管，而高速动作的GaN则有望取代Si-MOSFET，从而适应更高频率的应用。

## 6-2 SiC器件 (SiC Devices / SiCデバイス)

### (a) SiC晶圆 (SiC Wafer / SiCウェハ)

SiC晶体存在多种晶体结构，如立方晶的3C-SiC或六方晶的4H-SiC、6H-SiC等，功率器件主要使用4H-SiC。与Si晶体不同，SiC是通过升华法来生长晶体的，其晶体生长速度非常慢，这是提高良率和降低成本的难题。因此，SiC晶圆的结晶生长速度与Si相比为1/1000的程度。而且，SiC晶圆口径目前为4~6英寸（100~150 mm），与Si晶圆的口径（200~300 mm）相比要小。由于这些原因，生产效率低，成本也非常高。解决SiC器件普及的一大课题就是降低晶圆成本。

### (b) SiC器件的验证与产品化 (Device Demonstration and Commercialization / デバイス実証・製品化)

SiC器件方面，最初产品化的是SBD，于2001年由英飞凌（Infineon）公司开始销售。通常，耐压600V的Si二极管中，双极性器件pin二极管被使用，而SiC中，单极性器件SBD也能获得同等的导通电压。将双极性器件改为单极性器件，可以从根本上减少 **反向恢复损耗 (Reverse Recovery Loss / リカバリー損失)**（参考图6-4）。由于反向恢复引起的噪声降低和开关损耗降低的需求强烈，从适配器和大型电源开始使用。

之后，在电机应用中的逆变电路中，SiC-SBD与Si-pin二极管替换，开关损耗得到降低。但Si-IGBT依然存在，反向恢复损耗和IGBT的关断损耗并未减少的效果很有限。于是，SiC-SBD和Si-IGBT组合的混合型产品被商业化，2012年在东京地铁银座线上实现了商业化。

![图 6-4 SiC-SBD和Si-pin二极管的反向恢复波形比较](figure_6-4.png)

然而，使用与Si相同的工艺来制造SiC-MOSFET的商业化却遇到了困难。截面结构与Si-MOSFET相同，制造工艺也使用相同的工程，但由于是化合物半导体，MOS界面的界面準位密度高，沟道迁移率仅为Si的1/10左右。因此，即使在高临界电场下可以降低漂移电阻，但沟道电阻高，无法发挥出材料极限所预期的低导通电阻。

为此，改善沟道迁移率的研究开发活跃进行，虽然在平面结构上进展不大，但采用了迁移率较高的面，并实现了低导通电阻的 **平面栅极 (Planar Gate / プレーナーゲート)** 器件，以高耐压器件为中心开始产品化。之后，为了进一步降低沟道电阻，采用了沟道长度可以缩短的 **沟槽栅极 (Trench Gate / トレンチゲート)** 结构（参考图6-5），从2017年起多家公司实现了商业化。目前，SiC-MOSFET已在电动汽车的SiC-MOSFET中得到应用，并已取代Si-IGBT的全SiC模块在小田急线和山手线、东海道新干线（N700S系）等铁道中得到实用化。

现状是，SiC-SBD单体、SiC-MOSFET单体的分立器件、混合型SiC-SBD和Si-IGBT组合的模块以及结合了SiC-MOSFET和SiC-SBD的 **全SiC模块 (Full-SiC module / Full-SiCモジュール)** 已经产品化。分立器件的耐压为600V~1700V，模块则在耐压600V~3300V的范围内广泛展开。

![图 6-5 采用沟槽栅极的SiC-MOSFET截面结构](figure_6-5.png)

### (c) SiC器件的课题 (Challenges of SiC Devices / SiCデバイスの課題)

SiC功率器件，是为了实现超越Si功率器件极限的高性能，其验证和实用化正在进行中。但是，要积极取代Si功率器件，还面临着许多普及的障碍和课题，这与成本和信赖性有关。成本方面，晶圆成本高是主要原因，但工艺成本也很高。这是因为SiC材料非常硬，加工性差，且许多多晶型体共存，导致结晶缺陷容易产生，抑制良率和热处理温度也比Si高，导致设备昂贵。由于这些原因，生产性低、芯片成本高，现阶段被用于高性能可以弥补昂贵成本的应用中，尚未达到大规模普及。

信赖性方面也存在课题，MOS界面和p-n二极管的安定性是首先要解决的问题。如前所述，因为是化合物半导体，MOS界面的準位密度比Si高10倍以上。因此，由于界面準位的电荷俘获，栅极阈值电压的变动也高出10倍以上。在界面準位附近有电子俘获，在阈值电压附近有空穴俘获，当栅极长时间施加电压时，阈值电压会变动。

SiC-MOSFET也和Si-MOSFET一样，在逆变电路中，需要使用反并联的二极管，如果可以使用体二极管，就不需要并联SiC-SBD。但是，体二极管工作时，由于漂移层中基底面缺陷的影响，导通电压上升。这会导致漂移层内的载流子再结合能增加，基底面缺陷扩大。为了对策，正在研究在不降低基底面缺陷的情况下增加电导率的方法，以及使用SBD来避免体二极管工作的方法。

## 6-3 GaN器件 (GaN Devices / GaNデバイス)

### (a) GaN晶圆 (GaN Wafer / GaNウェハ)

蓝色发光二极管和激光器中使用的GaN是众所周知的，但发光器件的芯片面积小，因此使用的GaN晶圆也小，2英寸是主流。功率器件所要求的大面积芯片制造，目前还没有看到途径。因此，GaN功率器件的制造，是通过在Si基板上进行 **异质外延生长 (heteroepitaxial growth / ヘテロエピタキシャル成長)** 的手段。Si基板上生长GaN晶体时，由于晶格不匹配达-17%之大，需要夹入缓解晶格失配的 **缓冲层 (buffer layer / バッファ層)** 等。通过在Si基板上生长GaN层，实现了GaN晶体的高品质生长。这与SiC不同，解决晶圆成本的课题已初现曙光。

### (b) GaN器件的验证与产品化 (GaN Device Demonstration and Commercialization / デバイス実証・製品化)

GaN中，难以通过p型和n型的离子注入和扩散形成pn结，因此难以制造出像Si或SiC那样的纵向导通器件，也难以制造使用缓冲层的纵向功率MOSFET或IGBT。因此，利用晶体生长和电极形成来制造的横向器件——**HEMT (High Electron Mobility Transistor / 高電子移動度トランジスタ)** 被采用（参考图6-6）。HEMT结构中，在AlGaN/GaN界面由于自发极化和压电极化产生了高浓度的 **二维电子气 (2DEG / 2次元電子ガス)**，从而实现了移动。因此，沟道电阻和漂移电阻也能降低，低压下也能实现低导通电阻。要获得高耐压，需要拉大栅-漏极间距，但为了实现高耐压，需要加厚异质外延生长层。

![图 6-6 GaN-HEMT截面结构](figure_6-6.png)

### (c) GaN器件的课题 (Challenges of GaN Devices / GaNデバイスの課題)

GaN-HEMT的高速开关动作，已在器件单体验证，但实用化开始后，更进一步的普及仍面临以下三个主要课题：1) **电流崩塌 (Current Collapse / 電流コラプス)**，2) **常关型 (Normally-off / ノーマリーオフ)**，3) **雪崩耐量 (Avalanche Tolerance / アバランシェ耐量)**。

**电流崩塌** 是指在器件上施加电压后，电流流过时导通电阻增加的现象。产生原因是界面或晶体缺陷引起的电子俘获。施加电压时，2DEG沟道中的电子被电场加速，俘获到表面或异质结生长层中的缺陷中。之后，即使栅极导通，被俘获的电子也会形成负的固定电荷，使2DEG沟道的电子难以恢复，导通电阻增加。

**常关型** (Normally-off)，是指栅极电压为零时器件处于关断状态。如前所示，Si功率器件是MOS栅极，而SiC功率器件是p基区的反向偏置沟道来形成导通状态，因此栅极电压为零时是关断的，属于常关型。然而，GaN-HEMT即使栅极无偏置，AlGaN/GaN界面也会形成2DEG。因此，栅极电压为零时沟道也是导通的，属于常开型器件。

![图 6-7 GaN-HEMT的常关型化结构](figure_6-7.png)

为了实现常关型化，正在研究三种结构（参考图6-7）。1) p-栅极，2) AlGaN层再生+MIS栅极，3) **级联 (Cascode / カスコード)** 连接。

**雪崩耐量** (Avalanche Tolerance) 指的是器件的抗击穿能力。在Si或SiC功率器件中，雪崩击穿时产生的空穴会通过p基区排出，即使发生雪崩击穿也不会立即损坏，具有一定程度的耐量。然而，GaN-HEMT中不存在连接到源极的p层，因此空穴难以排出。因此，雪崩击穿产生的空穴在内部积累，其空穴电荷使电场上升，进一步促进雪崩击穿的正反馈发生，导致器件损坏。实现常关型的p栅极结构，虽然可以经由p-GaN层向栅极排出空穴，但由于AlGaN/GaN异质界面存在势垒，无法快速排出空穴，其雪崩耐量约为Si-MOSFET的1/1000，非常小。功率器件要求包括异常情况在内的安全运行，因此，提高GaN-HEMT的雪崩耐量是普及的一大课题。
