# 5 IGBT

## 5-1 基本构造与工作原理 (Basic Structure and Operation / 基本構造と動作)

IGBT是一种与功率MOSFET相同的 **MOS门 (MOS Gate / MOSゲート)** 型开关元件。如图5-1所示，其表面具有MOS门结构，**发射极 (Emitter / エミッタ)** 连接到n+发射极层和p基区，**集电极 (Collector / コレクタ)** 连接到p集电极层。p基区/n-漂移层/p集电极层的pnp晶体管与MOS门结合形成，因此被命名为 **绝缘栅双极晶体管 (IGBT - Insulated Gate Bipolar Transistor)** 的缩写。图中展示的是 **沟槽栅极 (Trench Gate / トレンチゲート)** 结构，但也有使用与功率MOSFET相同的 **平面栅极 (Planar Gate / プレーナーゲート)** 结构的情况。

当对栅极施加电压时，会形成一个 **沟道 (Channel / チャネル)**，电子通过这个沟道从n+发射极层注入到n-漂移层。此时，p集电极层和n-漂移层形成的pn结变为正向偏置，p集电极层向n-漂移层注入空穴。这使得发射极-集电极之间导通（**导通状态 (On-state / オン状態)**），电流得以流过。

在 **关断状态 (Off-state / オフ状態)** 下，与功率MOSFET相同，p基区和n-漂移层之间的pn结上会形成 **空乏层 (Depletion Layer / 空乏層)** 来维持电压。但是，如果空乏层延伸到p集电极层，p集电极和n-漂移层形成的pn结就会被反向偏置，注入的空穴会引发 **雪崩击穿 (Avalanche Breakdown / アバランシェ降伏)**，从而导致器件在低于其设计耐压时损坏。因此，在设计IGBT的 **漂移层 (Drift Layer / ドリフト層)** 时，主要有两种设计方法。一种是防止空乏层到达p集电极层的设计，称为 **非穿通型 (NPT: Non-Punch Through / ノンパンチスルー)**。另一种是在p集电极层和漂移层之间设置一个高掺杂浓度的n-缓冲层（**n-buffer layer / n-バッファ層**），以阻止空乏层延伸，从而可以使漂移层做得更薄，这种设计被称为 **穿通型 (PT: Punch Through / パンチスルー)**。

IGBT的 **集电极电流-集电极电压特性 (Collector current - Collector voltage characteristics / コレクタ電流－コレクタ電圧波形)** 如图5-2所示。由于集电极侧的pn结需要正向偏置电压才能让电流开始流动，因此其电压-电流特性存在一个由该pn结电压决定的偏移电压，这一点与功率MOSFET的线性沟道电阻特性不同。这是由注入漂移层的电子和空穴共同作用（即 **电导率调制 (conductivity modulation / 導電率変調)**）引起的，它显著降低了漂移电阻。因此，尽管在零电流附近，功率MOSFET的 **导通电压 (On-voltage / オン電圧)** 更低，但在大电流区域，IGBT的导通电压通常更低。在关断状态下，IGBT与功率MOSFET一样，通过p基区-漂移层结的空乏层延伸来承受电压，当空乏层内的电场达到临界电场强度时，会发生雪崩击穿，这决定了其耐压。

![图 5-1 沟槽型IGBT和漂移层设计](figure_5-1.png)![图 5-2 IGBT的I-V特性](figure_5-2.png)

与仅靠电子（或空穴）导电的 **单极性器件 (Unipolar Device / ユニポーラ素子)** 不同，IGBT通过 **电导率调制 (Conductivity Modulation / 導電率変調)** 效应，显著降低了漂移层的电阻。单极性器件的材料电阻限制了其高耐压化，因此，在需要高耐压、低导通电阻的应用中，会使用IGBT和功率MOSFET。两者之间的分界电压大约在400~900V。

IGBT通过电导率调制以低导通电压传导大电流，但在关断操作时，需要时间来清除漂移层中积累的载流子。因此，与功率MOSFET相比，其 **关断时间 (Turn-off time / ターンオフ時間)** 更长，**关断损耗 (Turn-off Loss / ターンオフ損失)** 也更大。因此，它不适用于高的 **开关频率 (Switching Frequency / スイッチング周波数)**。正因为如此，对于需要在大电流（10A以上）和较低开关频率下工作的电机驱动等应用，通常使用IGBT；而对于需要在100kHz以上高开关频率下工作的电源等应用，则使用功率MOSFET。

## 5-2 开关特性 (Switching Characteristics / スイッチング特性)

通过增加从集电极注入的空穴，可以增加漂移层内的载流子密度，从而降低导通电压。但是，在关断时，所有这些载流子都必须被清除，这导致导通电压和 **关断时间 (Turn-off time / ターンオフ時間)** 之间存在明显的权衡关系。

为了解释导通电压和关断损耗之间的权衡关系，我们使用漂移层中的 **载流子分布 (Carrier Profile / キャリア分布)** 进行说明。这里，我们做一些简化假设：1）漂移层中的复合是一次线性的（参考图5-3）。2）p集电极注入效率可以设定。3）栅极电压在高速下工作，关断时沟道电流能迅速被切断。

![图 5-4 导通电压-关断损耗权衡关系的载流子分布依赖性](figure_5-4.png)![图 5-5 关断损耗的载流子比依赖性](figure_5-5.png)

导通电压 $V_{\text{on}}$ 是IGBT导通路径上各部分压降之和，即：

$$
V_{\text{on}} = V_{\text{pn}} + V_{\text{drift}} + V_{\text{ch}} = V_{\text{pn}} + R_{\text{drift}}I_{\text{c}} + R_{\text{ch}}I_{\text{c}} \quad (37)
$$

其中，为了让空穴注入到n-漂移层中，需要在集电极侧pn结上施加的正向偏置电压为 $V_{\text{pn}}$，$V_{\text{drift}}$ 是漂移层的压降，$V_{\text{ch}}$ 是沟道的压降。$V_{\text{pn}}$ 由集电极侧的载流子密度决定，表达式为：

$$
V_{\text{pn}} = \frac{kT}{q} \ln\left(\frac{n p_e}{n_i^2}\right) \quad (38)
$$

其中，$p_e$ 是发射极侧的载流子浓度，$p_c$ 是集电极侧的载流子浓度。$R_{\text{drift}}$ 由电导率调制增加的载流子浓度分布 $n(x)$ 决定。

$$
\frac{1}{R_{\text{drift}}} = q(\mu_n+\mu_p)\int n(x)dx \quad (39)
$$

其中，$\mu_n$ 是 **电子迁移率 (electron mobility / 電子移動度)**，$\mu_p$ 是 **空穴迁移率 (hole mobility / ホール移動度)**。另一方面，功率MOSFET同样在式(18)中有所表示。关断时，需要寻求漂移层的空穴排出。漂移层中积累的载流子一经排出，空乏层便会上升。空乏层厚度 $W_{\text{dep}}$ 与集电极电压 $V_{\text{ce}}$ 的关系为：

$$
W_{\text{dep}}(t) = \sqrt{\frac{2\epsilon_s V_{\text{ce}}(t)}{qN_{\text{drift}}}} \quad (40)
$$

因此，关断时漂移层内的电荷密度 $Q_{\text{drift}}$ 为：

$$
Q_{\text{drift}}(t) = Q_0 - Q_{\text{dep}}(t) = \frac{q(p_e+p_c)l_{\text{drift}}}{2} - J_n t \quad (41)
$$

而且，$Q_{0}$ 是关断前的电荷密度，$Q_{\text{dep}}$ 是空乏化时排出的电荷密度，$J_n$ 是漂移层中的电子电流，$t$ 是时间。$J_n$ 是漂移电流与扩散电流之和，可表示为：

$$
J_n = \frac{\mu_n J_c - qD_a \frac{dn(x)}{dx}}{\mu_n+\mu_p} = \frac{\mu_n J_c - qD_a \frac{p_e-p_c}{l_{\text{drift}}}}{\mu_n+\mu_p} \quad (42)
$$

因此，排出电荷 $Q_{\text{dep}}$ 是将空乏层 $W_{\text{dep}}$ 用尽所致，所以：

$$
Q_{\text{dep}}(t) = q \int_0^{W_{\text{dep}}} n(x)dx \approx qp_eW_{\text{dep}}(t) + \frac{qp_e}{2l_{\text{drift}}}[W_{\text{dep}}(t)]^2 = J_n t \quad (43)
$$

通过解析式(40)、(42)、(43)可以求解 $V_{\text{ce}}(t)$。与功率MOSFET一样，关断损耗是电压电流重叠增加的过程（**米勒期间 (Miller period / ミラー期間)**）和集电极电流减少的过程（**电流切断期间 (current cut-off period / 電流切替わり期間)**）中产生的。米勒期间中，集电极电流是恒定的，此期间的损耗 $E_f$ 为：

$$
E_f = \int I_c V_{\text{ce}}(t) dt \quad (44)
$$

而且，$t_{tf}$ 是集电极电压达到电源电压 $V_{\text{DC}}$ 所需的时间。电流切换期间流过的电流，是为了排出漂移层内残留载流子而流动的电流，在此期间产生的损耗 $E_{tf}$ 为：

$$
E_{\text{tf}} = \int V_{\text{ac}} I_{\text{tail}} dt = V_{\text{ac}}Q_{\text{drift}}(t_{vr}) \quad (45)
$$

$E_f$ 和 $E_{tf}$ 的和即为关断损耗 $E_{\text{off}}$。

将这些式子计算出的结果如图5-4所示。漂移层内的总载流子量增加会导致导通电压降低，但关断损耗会增加，呈现出权衡关系。这个权衡关系通过减小 $p_e/p_c$ 比值得到改善。为了实现低的权衡关系，发射极侧浓度高、集电极侧浓度低的载流子分布是有效的。这是因为，漂移层内的载流子排出和集电极电压上升的方式会延伸。$p_e/p_c$ 比值越大，空乏层会越早延伸，集电极电压会越早上升。

![图5-6 IGBT在大电流关断时的波形](figure_5-6.png)

此外，当空乏层延伸时，如果集电极电压上升，集电极侧的空乏层会变宽，但集电极电流几乎不变（参考图5-5）。另外，关断后残留的电荷 $Q_{\text{drift}}$ 越多，关断损耗也越大。当 $p_e/p_c$ 比值较小时，发射极侧会存在大量载流子，因此开始时空乏层容易延伸，$E_{\text{off}}$ 较小。但是，在与导通电压相同的条件下，如果减小 $p_e/p_c$ 比值，$Q_{p}$ 会增大，空乏化所需时间变长，$E_{f}$ 会增大。综上所述，可以估计最佳的 $p_e/p_c$ 比值在0.2~0.3左右。

接下来，介绍功率MOSFET和IGBT的开关波形差异。功率MOSFET的关断动作是基于栅极电荷的充放电，而双极性动作的IGBT则需要额外考虑载流子的注入和抽出。在功率MOSFET中，**米勒期间 (Miller period / ミラー期間)** 中集电极电压上升，但IGBT中是 $V_{\text{ce}}$ 上升后，$I_{\text{c}}$ 才下降，这是因为反向沟道被消除，如图5-6的大电流关断波形所示。电路内的电流路径切换完成之前，IGBT必须持续导通，因此在导通状态下，大量载流子存在于漂移层中。为了排出这些大量的载流子，需要集电极电流持续流过。因此，首先 $V_{\text{ce}}$ 上升，之后 $I_{\text{c}}$ 继续流动。当 $V_{\text{ce}}$ 达到电源电压后，空乏层不会再延伸，漂移层中的载流子是通过扩散和复合慢慢排出的，残留的载流子会急剧减少，形成缓慢下降的 **拖尾电流 (tail current / テール電流)**。

开关时的 $C_{\text{ge}}$ 和 $C_{\text{gc}}$ 的充放电通过栅极电阻进行，与功率MOSFET一样控制栅极电压的速度。但是，通过减小栅极电阻来快速关断，漂移层内残留的载流子会增加，导致 $V_{\text{ce}}$ 上升。如图5-7所示，当载流子残留时，空乏层会进一步延伸，即使施加的电压低于耐压，内部电场也可能达到临界电场强度，引发 **雪崩击穿 (avalanche breakdown / アバランシェ降伏)**。这种现象被称为 **动态雪崩 (dynamic avalanche / ダイナミックアバランシェ)**。发生动态雪崩时，漂移层内会新产生电子-空穴对，使空乏层延伸得更慢，载流子排出恶化。结果是，$dV/dt$ 变小，关断时间变长。由于这个原因，单纯减小栅极电阻来降低 $E_{\text{off}}$ 是有局限的，而IGBT中，通过抑制动态雪崩的发生来减小栅极电阻，从而降低 $E_{\text{off}}$。

![图 5-7 动态雪崩对关断波形的影响](figure_5-7.png)![图 5-8 负电容对关断波形的影响](figure_5-8.png)

关断波形中也可以看到双极性动作的影响。如果 $V_{\text{ce}}=0$， $C_{\text{gc}}$ 是由栅极氧化膜容量决定的，$V_{\text{ce}}$ 变化时，它也是恒定的。然而，在关断状态下，集电极上施加高电压。这导致关断动作中 $V_{\text{ce}}$ 上升时，栅极-漏极之间的空乏层容量的影响变小。

### 5-3 破坏耐量 (Destruction Toughness / 破壊耐量)

与功率MOSFET一样，IGBT在高电压、大电流下也容易损坏。这里，我们将说明与器件内部的短路耐量和击穿耐量相关的主要损坏模式。如图5-9所示，IGBT内部的n+发射极层、p基区、n-漂移层和p集电极层形成了 **npn晶体管 (npn transistor)** 和 **pnp晶体管 (pnp transistor)**，这两者相互连接构成了 **寄生晶闸管 (parasitic thyristor / 寄生サイリスタ)**。晶闸管是一种一旦导通，即使栅极电压归零也会维持导通状态的元件。在关断操作中，p基区会流过空穴电流 $I_h$，如果p基区的电阻过高，npn晶体管就会导通，从而发生 **闭锁 (latch-up / ラッチアップ)**。一旦发生闭锁，就无法关断，器件会因过电流而损坏。因此，在p基区表面设置高浓度p+接触层，降低p基区的电阻，以防止闭锁，这种结构被称为 **非闭锁IGBT (non-latch-up IGBT / ノンラッチアップIGBT)**。

![图 5-9 非闭锁IGBT结构和寄生晶闸管](figure_5-9.png)

IGBT普及的一个原因，是与MOS栅极驱动的功率器件相比，它作为双极性动作的元件，其关断比晶闸管和GTO更高速，且破坏耐量更大。由于器件损坏，IGBT的关断需要称为 **短路耐量 (short-circuit withstand time / 短絡耐量)** 的大 $I_c$ 遮断能力，通常设计为能承受额定电流的2~3倍。如图5-10所示，IGBT主要用于电机驱动的 **逆变电路 (inverter circuit / インバータ回路)**。如果逆变电路的任一臂发生故障，例如上臂或下臂的IGBT同时导通（**臂短路 (arm short-circuit / アーム短絡)**）或电机本身损坏（**负载短路 (load short-circuit / 負荷短絡)**），IGBT就会进入短路状态。

### 5-4 构造的演变 (Evolution of Structure / 構造の変遷)

如前所述，IGBT的低损耗化是通过改善 $E_{\text{off}}-V_{\text{on}}$ 的权衡关系来实现的，而改变 **载流子分布 (carrier profile / キャリアプロファイル)** 是有效的。为此，通过减薄 **pin二极管 (pin diode)** 的漂移层、降低漂移电阻、改善载流子注入等观点来改进权衡关系。这也是IGBT结构演变的原因。

![图 5-11 IGBT的结构演变](figure_5-11.png)

主要的结构演变如图5-11所示。IGBT开发初期，是在p+基板上生长n-外延层来形成的。之后，在表面形成了MOS栅极结构。由于p+基板较厚，空穴注入量难以从集电极侧控制，因此，采用了 **裸晶圆 (raw wafer)** 结构，在其耐压所需的厚度处进行研磨，然后从背面注入p型离子形成p集电极层，实现了 **薄晶圆 (thin wafer / 薄ウェハ)** NPT结构。此后，随着工艺技术的发展，又实现了 **场截止型 (Field-Stop / フィールドストップ, FS)** IGBT，其名称来自英飞凌（Infineon）公司。

![图 5-12 注入增强(IE)和载流子存储(CS)结构及其对载流子分布的影响](figure_5-12.png)
![图 5-13 反向导通(RC)-IGBT的截面结构](figure_5-13.png)

此外，**反向导通IGBT (Reverse Conducting IGBT / RC-IGBT)** 也被商业化。通常，在逆变电路中，电流从发射极流向集电极，但也有反向流动的需求。通常，IGBT是反向截止的，因此需要并联一个pin二极管。而RC-IGBT将IGBT和集电极侧的元件集成为一个芯片，通过共用引线键合和终端部分，实现了比分立器件更小的芯片尺寸，从而有望实现恒定功率下的成本降低。
